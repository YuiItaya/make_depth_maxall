# テスト

合成データ（小さな四角形のShapefile）で処理全体と各関数を確かめる単体テストが `tests/` にあります。
GitHub に push すると GitHub Actions（`.github/workflows/tests.yml`）で自動実行されます。
実行環境は本番と同じ Windows ＋ Python 3.14 です。

## 手元での実行

```powershell
venv\Scripts\python.exe -m unittest discover -s tests -t tests -v
```

1分程度で終わります。中間ファイルは一時フォルダに作られ、終了後に削除されます。

## テストの内容

| ファイル | 確かめていること |
|---|---|
| `test_pipeline.py` | 重なる範囲は高いランクが優先される／入力どうしの重なりは最大ランク／低優先データは通常データが無い範囲だけ埋める／出力にZ値が残らない・指定座標系と出力フィールド名／切り出し範囲の外を除く／固定rank・式テンプレート（浸水深m）／不正な形状の修復／河川別出力が各河川の入力だけになる |
| `test_split_reuse.py` | 河川別出力でランク分解結果を再利用しても、紛らわしい入力名（`M` と `M_1`）で他の河川のデータが混ざらない／再利用しない方法と結果が一致する |
| `test_units.py` | 入力名の一意化（中間ファイル名の衝突防止）・設定の検証エラー・式テンプレートの境界値・変換表・固定rank・出力フィールド名・面だけの抽出・切り出し範囲の検証 |

期待値は仕様（高いランク優先、低優先は通常データが無い範囲だけ）からその場で計算しています。
面の切り取りは緯度経度（EPSG:6668）で行われるため、比較も緯度経度で行い、
食い違いの面積を平面直角座標（EPSG:6677）の m² で測っています（許容 0.01 m²）。

## テストを追加するとき

`tests/helpers.py` の `write_shp`（合成Shapefileの作成）、`TempWorkdirTestCase.run_pipeline`
（一時フォルダでの実行）、`rank_geometries`（出力のランク別形状）、`assertAreaClose`
（面積の食い違いの確認）を使うと短く書けます。
