# 最大包絡シェープファイル作成 操作ガイド

## 起動方法

Pythonで起動する場合:

```powershell
python make_depth_maxall.py
```

exe版で起動する場合:

```powershell
dist\make_depth_maxall\make_depth_maxall.exe
```

引数なしで起動するとGUIが開きます。YAML設定ファイルを指定して処理する場合は、次のように実行します。

```powershell
python make_depth_maxall.py 設定ファイル.yaml
```

## 基本手順

1. `追加` から入力Shapefileを選択します。
2. 各行の `フィールド` で、浸水深ランク又は浸水継続時間ランクとして読むフィールドを指定します。
3. フィールド値ではなくShapefile単位でrankを指定する場合は、`固定rank` をオンにしてrank整数を入力します。
4. 河川別出力で同じ河川として扱う場合は、それらを選択して `選択を同一河川出力グループ` を押します。
5. 入力データを同じまとまりとして扱う場合は、それらを選択して `選択を同一データグループ` を押します。
6. 必要に応じて `低優先` をオンにします。
7. 必要に応じて `地図で範囲選択` から処理範囲を矩形指定します。
8. `出力ファイル`、`出力フィールド`、`出力座標系` を設定します。
9. `実行` を押します。

## 出力

通常は、`出力ファイル` に指定したShapefileを1つ作成します。

`河川・グループ別出力も作成` をオンにすると、通常の出力に加えて、河川単位のShapefileも作成します。

入力データ処理用の `データグループ名` とは別に、河川別出力用の `河川出力グループ名` を設定できます。デフォルトでは `データグループ名` と同じ値です。例えば `○○川_上流` と `○○川_下流` を別データグループとして処理しつつ、河川別出力ではどちらも `○○川` として1つのShapefileにまとめられます。

複数行を選択して `選択を同一河川出力グループ` を押すと、選択した行の `河川出力グループ名` を一括で揃えられます。

グループ別出力は、通常出力が `output.shp` の場合、同じフォルダの `output_by_group` フォルダに `<河川出力グループ名>.shp` として保存されます。

出力（通常・グループ別とも）は書き出し前に不正なジオメトリ（自己交差など）を修復し、書き出し後にも読み戻して再確認します。座標変換やShapefileの座標精度への丸めで不正になった箇所もこの段階で修復されます。修復した場合はログに `出力ジオメトリを修復しました（n件）。` と表示されます。

同じファイル名のShapefileを複数追加した場合、デフォルトのデータグループ名も同じになります。この場合は `maxall`, `maxall_2` のように自動で連番を付け、グループ別出力が衝突しないようにします。`選択を同一データグループ` で明示的にグループ化した入力は、1つのデータグループとして処理します。

## 通常と低優先

`通常` は標準の入力データです。

`低優先` は、通常データより優先度を下げて扱う入力データです。既存の設定ファイルでは内部キーとして `is_extra` を使いますが、GUI上は `低優先` と表示します。

## フィールド値と変換表

入力フィールドは、基本的に `1` から `7` の整数rankを想定しています。

文字列の浸水深区分や、`0.5`、`5.0` のような実深さの値をrankに変換したい場合は、該当行を選択して `変換表設定` を押します。

入力フィールドに浸水深(m)や浸水継続時間(分)の生値が入っている場合は、該当行を選択して `式テンプレート` を押します。
登録済みテンプレートを選ぶと、実行時に各レコードの値からrankを計算します。
設定画面では、`計算` を押すと同一グループ内の全レコードを計算し、変換後rankごとの件数を確認できます。

フィールドにrankや浸水深区分がなく、ファイル名だけで浸水深を表している場合は、該当行で `固定rank` をオンにします。この場合、そのShapefile内の全ジオメトリを指定したrankとして扱います。

例:

| ファイル名の例 | 固定rank |
| --- | --- |
| `L2_0.0-0.5m.shp` | `1` |
| `L2_0.5-3.0m.shp` | `2` |
| `L2_3.0-5.0m.shp` | `3` |
| `L2_5.0-10.0m.shp` | `4` |
| `L2_10.0-20.0m.shp` | `5` |

登録済み式テンプレート:

| テンプレート | rank化ルール |
| --- | --- |
| 浸水深(m) | `0=0`, `0<x<0.5=1`, `0.5以上3未満=2`, `3以上5未満=3`, `5以上10未満=4`, `10以上20未満=5`, `20以上=6` |
| 浸水継続時間(分) | `0=0`, `0<x<720=1`, `720以上1440未満=2`, `1440以上4320未満=3`, `4320以上10080未満=4`, `10080以上20160未満=5`, `20160以上40320未満=6`, `40320以上=7` |
| 浸水継続時間(時間) | `0=0`, `0<x<12=1`, `12以上24未満=2`, `24以上72未満=3`, `72以上168未満=4`, `168以上336未満=5`, `336以上672未満=6`, `672以上=7` |
| 浸水継続時間(秒) | `0=0`, `0<x<43200=1`, `43200以上86400未満=2`, `86400以上259200未満=3`, `259200以上604800未満=4`, `604800以上1209600未満=5`, `1209600以上2419200未満=6`, `2419200以上=7` |

警告表示の意味:

- `▲`: 変換表がないと処理できない値があります。
- `△`: 処理はできますが、rankではなく実深さなどの値である可能性があります。

## YAML設定

GUIの `YAML保存` で現在の設定を保存できます。保存した設定は `YAML読込` で再利用できます。

既存YAMLから処理範囲と出力座標系だけを取り込みたい場合は、処理範囲欄の `YAMLから範囲/座標系読込` を使います。この操作では、入力ファイル一覧、出力ファイル名、出力フィールド、変換表などは変更しません。

YAML読込時に入力ファイルが存在しない場合でも、設定は読み込まれます。存在しない入力ファイルは一覧に `▲` で表示されます。YAML保存も可能ですが、そのまま実行すると入力検証で停止します。

文字列や実深さをrankへ変換する設定は、YAML内では `value_mapping` として保存されます。

式テンプレートでrankを計算する設定は、YAML内では `value_reclass` として保存されます。

Shapefile単位で固定rankを指定した設定は、YAML内では `fixed_value` として保存されます。

## 中間ファイル

デフォルトでは、処理後に中間ファイルを削除します。確認用に残したい場合は `中間ファイルを残す` をオンにしてください。

## 注意事項

- ShapefileのCRSが未設定の場合は処理を停止します。
- 出力フィールド名はShapefileの制約上、半角英数字とアンダースコアを使い、10文字以内にしてください。
- 地図背景は地理院タイルを取得します。オフライン環境では背景地図が表示できない場合があります。
