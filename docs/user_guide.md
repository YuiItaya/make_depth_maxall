# 最大包絡シェープファイル作成 操作ガイド

## 起動方法

Pythonで起動する場合:

```powershell
python make_depth_maxall.py
```

exe版で起動する場合:

```powershell
dist\make_depth_maxall\make_depth_maxall.exe
```

引数なしで起動するとGUIが開きます。YAML設定ファイルを指定して処理する場合は、次のように実行します。

```powershell
python make_depth_maxall.py 設定ファイル.yaml
```

## 基本手順

1. `追加` から入力Shapefileを選択します。
2. 各行の `フィールド` で、浸水深ランク又は浸水継続時間ランクとして読むフィールドを指定します。
3. フィールド値ではなくShapefile単位でrankを指定する場合は、`固定rank` をオンにしてrank整数を入力します。
4. 1河川が複数ファイルに分かれている場合は、それらを選択して `選択を同一グループ` を押します。
5. 必要に応じて `低優先` をオンにします。
6. 必要に応じて `地図で範囲選択` から処理範囲を矩形指定します。
7. `出力ファイル`、`出力フィールド`、`出力座標系` を設定します。
8. `実行` を押します。

## 通常と低優先

`通常` は標準の入力データです。

`低優先` は、通常データより優先度を下げて扱う入力データです。既存の設定ファイルでは内部キーとして `is_extra` を使いますが、GUI上は `低優先` と表示します。

## フィールド値と変換表

入力フィールドは、基本的に `1` から `7` の整数rankを想定しています。

文字列の浸水深区分や、`0.5`、`5.0` のような実深さの値をrankに変換したい場合は、該当行を選択して `変換表設定` を押します。

フィールドにrankや浸水深区分がなく、ファイル名だけで浸水深を表している場合は、該当行で `固定rank` をオンにします。この場合、そのShapefile内の全ジオメトリを指定したrankとして扱います。

例:

| ファイル名の例 | 固定rank |
| --- | --- |
| `L2_0.0-0.5m.shp` | `1` |
| `L2_0.5-3.0m.shp` | `2` |
| `L2_3.0-5.0m.shp` | `3` |
| `L2_5.0-10.0m.shp` | `4` |
| `L2_10.0-20.0m.shp` | `5` |

警告表示の意味:

- `▲`: 変換表がないと処理できない値があります。
- `△`: 処理はできますが、rankではなく実深さなどの値である可能性があります。

## YAML設定

GUIの `YAML保存` で現在の設定を保存できます。保存した設定は `YAML読込` で再利用できます。

YAML読込時に入力ファイルが存在しない場合でも、設定は読み込まれます。存在しない入力ファイルは一覧に `▲` で表示されます。YAML保存も可能ですが、そのまま実行すると入力検証で停止します。

文字列や実深さをrankへ変換する設定は、YAML内では `value_mapping` として保存されます。

Shapefile単位で固定rankを指定した設定は、YAML内では `fixed_value` として保存されます。

## 中間ファイル

デフォルトでは、処理後に中間ファイルを削除します。確認用に残したい場合は `中間ファイルを残す` をオンにしてください。

## 注意事項

- ShapefileのCRSが未設定の場合は処理を停止します。
- 出力フィールド名はShapefileの制約上、半角英数字とアンダースコアを使い、10文字以内にしてください。
- 地図背景は地理院タイルを取得します。オフライン環境では背景地図が表示できない場合があります。
